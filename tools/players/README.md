# 選手DB の作成スクリプト

5大リーグの選手DB (`data/players-YYYY-YY.tsv`) をウィキペディアから作るためのスクリプトです。シーズンが変わったときに作り直すために残しています。

## 使い方

作業用のフォルダ (例: `work/`) を用意し、順に実行します。取得した記事は `work/wiki/` にキャッシュされます。

```
python clubs.py work          # 各リーグの今季の参加クラブ → work/clubs.json
python build.py work work     # 選手DB → work/players-2026-27.csv と work/report.json
```

`wk.py` と `romaji.py` は同じフォルダに置いたまま使います。`build.py` は、作業フォルダに `manual_kana.json` (英語表記 → カタカナの手作業の対応表) があれば使います。

## データの出どころ

- 参加クラブ: 日本語版ウィキペディアの各リーグ記事の「所属クラブ」
- 在籍選手・背番号・ポジション: 英語版ウィキペディアの各クラブ記事の現所属メンバー
- カタカナの選手名: 日本語版の選手記事 → Wikidata の日本語名 → 日本語版クラブ記事のメンバー表 → `manual_kana.json` の順に探す

ウィキペディアは短時間に多く読むと 429 (アクセス過多) を返します。`wk.py` は待ってから再試行します。
