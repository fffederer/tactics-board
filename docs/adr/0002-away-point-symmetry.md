# アウェイの配置は線対称ではなく点対称で求める

当初の仕様では、アウェイの配置はセンターラインを軸とした線対称(左右反転)だった。しかし左右反転だけだと、ホームの右SBとアウェイの右SBがコートの同じ側に並び、向かい合ってしまう。実際の試合では、右SBは相手の左SBと向かい合う。そこで、コート中心を軸とした180度回転(点対称)に変えた。フォーメーションはホームが右へ攻める向きで1つだけ作り、アウェイではこれを点対称に置き直して使う。

## Consequences

- フォーメーションを作るときは、コート上側がそのチームの左サイドになる。この向きで作れば、両チームとも正しいサイドに並ぶ。
