# スプレッドシートと GAS の準備手順

戦術ボードをスプレッドシートにつなぐための手順です。Google アカウントでの操作なので、ご自身で行います。所要時間は15分ほどです。

## 1. スプレッドシートを作る

1. Google にログインした状態で https://sheets.new を開きます。新しいスプレッドシートが作られます。
2. 左上の「無題のスプレッドシート」をクリックし、名前を「戦術ボードDB」に変えます。

## 2. GAS のコードを貼り付ける

1. スプレッドシートのメニューで「拡張機能」→「Apps Script」を開きます。
2. 左上の「無題のプロジェクト」をクリックし、名前を「戦術ボードAPI」に変えます。
3. VS Code で `tactics-board/gas/Code.gs` を開き、Ctrl + A で全選択して Ctrl + C でコピーします。
4. Apps Script のエディタに最初からある `function myFunction() { }` をすべて消し、Ctrl + V で貼り付けます。
5. Ctrl + S で保存します。

## 3. 初期設定 (setup) を実行する

1. エディタ上部の関数の選択欄で「setup」を選び、「実行」を押します。
2. 「承認が必要です」と出たら、次の順に進みます。自分で作ったスクリプトなので、この警告は問題ありません。
   1. 「権限を確認」を押し、自分のアカウントを選びます。
   2. 「このアプリは Google で確認されていません」と出たら、左下の「詳細」を押します。
   3. 「戦術ボードAPI(安全ではないページ)に移動」を押します。
   4. 「許可」を押します。
3. 下の実行ログに「実行完了」と出れば成功です。
4. スプレッドシートに戻ると、「選手DB」と「フォーメーション」の2枚のシートができています。選手DBには、動作確認用のサンプル選手 (3チーム) が入っています。本番のデータは手順4で入れ替えます。

setup は、空のシートにだけ初期データを書き込みます。もう一度実行しても、入力済みのデータは消えません。

## 4. ウェブアプリとしてデプロイする

1. エディタ右上の「デプロイ」→「新しいデプロイ」を押します。
2. 「種類の選択」の歯車アイコンを押し、「ウェブアプリ」を選びます。
3. 次のとおり設定します。
   - 説明: 空欄でかまいません
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
4. 「デプロイ」を押します。承認を求められたら、手順3と同じように許可します。
5. 表示された「ウェブアプリ」の URL をコピーします。`https://script.google.com/macros/s/…/exec` の形です。

「全員」は、URL を知っている人なら Google にログインせずに使えるという意味です。URL は他人に教えないでください (ADR-0001)。

### 動作確認

コピーした URL をブラウザで開きます。`{"ok":true,"players":[…` で始まる文字が表示されれば成功です。

## 5. アプリをつなぐ

1. 戦術ボードを開き、ヘッダーの「接続設定」を押します。
2. コピーした URL を貼り付け、「保存して再読み込み」を押します。
3. ヘッダーの「サンプルデータ」の表示が消えれば、スプレッドシートにつながっています。

URL は、その端末のブラウザにだけ保存されます。PC と iPhone で、それぞれ一度設定してください。iPhone では、PC の接続設定にある「iPhone 用のリンクをコピー」でコピーしたリンクを開くと、URL の入力を省けます。このリンクが iPhone で使えるのは、アプリを GitHub Pages に公開した後です。

## 選手DB を入れ替える

`data/players-2026-27.tsv` の選手 (5大リーグ96チーム) を選手DB に入れる手順です。入力規則は消えません。

1. スプレッドシートの「選手DB」シートを開きます。
2. A2 セルをクリックし、Ctrl + Shift + ↓ と Ctrl + Shift + → で、2行目から最後の行までを選びます。Delete キーで中身を消します。行は削除しないでください。
3. VS Code で `tactics-board/data/players-2026-27.tsv` を開き、Ctrl + A で全選択して Ctrl + C でコピーします。
4. スプレッドシートの A2 セルをクリックし、**Ctrl + Shift + V** (値のみ貼り付け) で貼り付けます。
5. 戦術ボードを再読み込みすると、新しい選手が選べるようになります。

表記を確認したほうがよい選手は `data/players-2026-27-review.md` にまとめています。直すときはシートを直接書き換えてください。

## GAS のコードを変更したとき

コードを貼り替えて保存しただけでは、ウェブアプリには反映されません。次の手順で更新します。

1. エディタのコードをすべて消し、新しい `gas/Code.gs` を貼り付けて保存します。
2. 関数の選択欄で「setup」を選び、「実行」を押します。入力済みのデータは消えません。シートの書式の修正が必要なときは、ここで直ります。
3. 「デプロイ」→「デプロイを管理」を開きます。
4. 鉛筆アイコンを押し、「バージョン」で「新バージョン」を選びます。
5. 「デプロイ」を押します。

この方法なら URL は変わりません。「新しいデプロイ」を作ると URL が変わるので、各端末で接続設定をやり直すことになります。

## うまくいかないとき

| 症状 | 確認すること |
|---|---|
| 「URL の形が違います」と出る | URL が `/exec` で終わっているか。`/dev` で終わる URL はテスト用で使えません。 |
| 「データを読み込めませんでした」と出る | デプロイの「アクセスできるユーザー」が「全員」になっているか。 |
| 「setup を実行してください」と出る | 手順3の setup を実行したか。シート名が「選手DB」「フォーメーション」のままか。 |
| フォーメーションを登録しても変わらない | ほかの端末では、アプリを開き直すと反映されます。 |
| フォーメーション名が「2004/4/2」のような日付になる | 古い `Code.gs` のままです。上の「GAS のコードを変更したとき」の手順で更新してください。 |
